Build & Code — Automation & Robotics starter project
=====================================================

AR-Starter-main.cpp is the file you write your code in.

How to use it (your teacher sets this up once):
  1. In VS Code, create a new VEX EXP project named "AR-Starter".
  2. Open the file "main.cpp" inside the project's "src" folder.
  3. Replace everything in it with the contents of AR-Starter-main.cpp.
  4. Save.

From then on, you only ever type your code between these two lines:

      // ===== WRITE YOUR CODE BELOW THIS LINE =====
      // ===== WRITE YOUR CODE ABOVE THIS LINE =====

Everything else is already set up for you. You'll learn what those
other lines do in Chapter 10.

Full walkthrough: open "Getting Started with Code" in the Build & Code book.
