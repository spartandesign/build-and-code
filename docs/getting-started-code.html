Getting Started with Code

This year you'll build robots and write the code that makes them move. This page gets you going in a few minutes: you'll send your very first program to a robot and watch a motor spin. You don't need to understand every word yet — just follow along. Come back here any time you need the basics.

The tool

You write code in Visual Studio Code (VS Code) with the VEX extension added on — your teacher has it set up on your computer. It runs on the computer in front of you, and your finished program travels down a USB-C cable into the robot's Brain. That's the whole idea: write on the computer, send it to the robot, watch it go.

Open the starter

Open the project called AR-Starter. You'll see something like this:

#include "vex.h"
using namespace vex;

// ---- Your devices (already set up for you) ----
// Plug your motor into Smart Port 1.
motor leftMotor = motor(PORT1);

int main() {
  vexcodeInit();   // gets the robot ready — leave this here

  // ===== WRITE YOUR CODE BELOW THIS LINE =====
  leftMotor.spin(forward);
  wait(2, seconds);
  leftMotor.stop();
  // ===== WRITE YOUR CODE ABOVE THIS LINE =====
}

Here's the only rule you need today: you write code only between the two purple lines. Everything else is already set up for you — leave it alone. (Curious what those other lines do? You'll find out in Chapter 10. For now, ignore them.) The three lines already in the region are your first program: spin the motor, wait 2 seconds, stop.

Send it to the robot

  1. Plug in. Connect the Brain to the computer with a USB-C cable and turn the Brain on. Make sure your motor is in Smart Port 1.
  2. Download. Click the Download button. It checks your code and sends it to the Brain.
  3. Run. Click Run. Watch the motor spin for two seconds and stop. 🎉

If something doesn't work, the most common reasons are a loose cable, the motor in the wrong port, or the Brain turned off — check those first.

Make one change

Now make it yours. Find this line:

wait(2, seconds);

Change the 2 to a 5, then Download and Run again. The motor now spins for five seconds. That's it — you just changed a program. Write, download, run, change, repeat: that loop is the whole job.

💻 You're a programmer now

Seriously — you wrote a program and a machine did what you said. From here on, you'll do a little more each time: set a speed, add a second motor, read a sensor. You never have to deal with the setup lines around your code; just write between the two purple lines, Download, and Run.

Remember: your code goes only between the // WRITE YOUR CODE lines.

⚠️ Stay safe

  • Before you Run, make sure the robot can't drive off the table — a program can make it move suddenly. Prop the wheels up or be ready to catch it.
  • Keep fingers, hair, and loose sleeves away from the spinning motor shaft and anything attached to it.
  • If your robot is meant to drive around, unplug the USB-C cable first — never let it drive while tethered.
  • Power the Brain down with the X button when you're done.

What's next

From here on, many chapters have a 💻 Code it box — just a few lines to type that bring your build to life: spin the gears you assembled, drive the toy you made, react to a sensor. You don't need to understand every part of the program to do them. Open the starter, write in the region, Download, and Run. When you're ready for the whole story of how a program works — what all those other lines mean — that's waiting for you in Chapter 10.
