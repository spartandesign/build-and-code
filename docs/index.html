Build & Code

An 18-week build-and-code course: structures, mechanisms, and programming, working from the engineering design process toward your own automated machines.

How to use this book

Each chapter teaches a concept, points you to the matching VEX Library article or video for diagrams and walkthroughs, and ends with a build and a set of questions. Work the chapters in order — later ones lean on skills from earlier ones. Use the Contents list to jump around; the chapter you're reading is always highlighted there.
