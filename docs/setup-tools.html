Set Up Your Tools

Before you can send code to a robot, you need two free tools on your computer: Visual Studio Code and the VEX Robotics extension. You'll install them yourself — it takes about ten minutes, and you only do it once. Follow the steps in order; you don't need to understand everything yet.

1 · Install Visual Studio Code

Your school installs approved apps through the Software Center — no admin password needed.

  1. Click the Windows Start button and type Software Center. Open it.
  2. Find Visual Studio Code (search for it at the top if you don't see it).
  3. Click it, then click Install. Give it a couple of minutes to finish.
  4. Open Visual Studio Code from the Start menu. A mostly-blank window with a menu bar down the left side is exactly right.

Don't see Software Center, or Visual Studio Code isn't listed? Raise your hand — your teacher will help.

2 · Add the VEX Robotics extension

The extension is what lets VS Code talk to your robot.

  1. On the far-left toolbar, click the Extensions icon — it looks like four little squares — or press Ctrl + Shift + X.
  2. In the search box, type VEX Robotics.
  3. Find the one named VEX Robotics (published by VEX Robotics) and click Install.
  4. When it's done, a VEX robot icon appears in that left toolbar. That's how you know it worked.

3 · Create your AR-Starter project

This is the project you'll open for the rest of the year.

  1. Click the VEX robot icon in the left toolbar.
  2. Choose New Project.
  3. For the platform pick EXP; for the language pick C++. Choose the plain/blank template if it offers a list.
  4. Name the project exactly AR-Starter and save it somewhere you'll remember (your Documents folder is fine).
  5. Click Create. On the left you'll see a src folder with a file called main.cpp inside it.

4 · Paste in the starter code

Open src → main.cpp. Select everything in it (Ctrl + A), delete it, then paste in the code below and save (Ctrl + S):

#include "vex.h"
using namespace vex;

// ---- Your devices (already set up for you) ----
// Plug your motor into Smart Port 1 on the Brain.
motor leftMotor = motor(PORT1);

int main() {
  vexcodeInit();   // gets the robot ready — leave this here

  // ===== WRITE YOUR CODE BELOW THIS LINE =====
  leftMotor.spin(forward);
  wait(2, seconds);
  leftMotor.stop();
  // ===== WRITE YOUR CODE ABOVE THIS LINE =====
}

Here's the only rule you need: you write your own code only between the two purple lines. Everything else is already set up for you — leave it alone. (Curious what those lines do? That's Chapter 10.)

5 · Test it

  1. Plug a motor into Smart Port 1 on your EXP Brain.
  2. Connect the Brain to your computer with the USB-C cable and turn the Brain on.
  3. Click Download to send the program to the Brain, then Run it.
  4. If the motor spins for two seconds and stops, your setup works. 🎉

If it doesn't move, the usual reasons are a loose cable, the motor in the wrong port, or the Brain turned off — check those first.

🧰 You're set up

That's the whole one-time setup. From now on you just open your AR-Starter project, write your code between the two purple lines, then Download and Run. You never have to touch the setup steps again.

Next: head to Getting Started with Code to send your first real program and make it your own.

⚠️ Stay safe

  • Before you Run, make sure the robot can't drive off the table — prop the wheels up or be ready to catch it.
  • Keep fingers, hair, and loose sleeves away from the spinning motor shaft.
  • Power the Brain down with the X button when you're done.
